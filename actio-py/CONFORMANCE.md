# Conformance — actio-py

Row by row: what the protocol requires, where this tree implements it, and the test that proves it.

- The normative statement is the protocol's own MUST/SHOULD, quoted or paraphrased with its
  location in `../doc/actio_protocol.md` (`doc L…`). Where the plan made a choice the protocol
  leaves open, the decision is cited as `D-x`.
- The implementation cell names the file and function in `src/actio/` that carries the rule.
- The tests cell names the rows that would fail if the rule broke:
  `unit:` a unit test in `tests/`, `agent:` a test driving a live `ActioAgent`,
  `e2e:` a two-agent scenario in `tests/test_e2e.py`, `interop:` a cross-implementation run in
  `interop/test_interop.py` (needs the TS reference at `../actio-ts` and its npm dependencies),
  `vectors:` a case in `tests/vectors/<kind>/`, driven by `tests/test_vectors.py`.
- A row that no test in this tree exercises says `no unit test` and names what covers it.
